# DRAW — 当たりを描く MVP

スマートフォンのブラウザで動く、外部ライブラリ不要のHTML/Canvasゲーム。

ゲーム画面は端末の表示高に固定し、盤面を左右いっぱいに広げ、残りの高さを使う。ページ全体はスクロールしない。縦横比に合わせて輪郭長を補正し、長さは盤面幅を基準に課金する。ルール・設定は別のダイアログで表示し、長い説明だけダイアログ内でスクロールする。

## GitHub Pages

`.github/workflows/pages.yml` がmainへのpush時にテストを実行し、`dist/`をGitHub Pagesに配置する。リポジトリのPages設定はGitHub Actionsを使用する。

## 起動

`python3 -m http.server 8080 --directory dist`

PCでは http://localhost:8080 を開く。スマホからは同じWi-Fi上のPCのLANアドレスの8080番へアクセスする。ホスト側の接続許可が必要な場合がある。`dist/index.html`をブラウザで直接開くことも可能。

## 調整

`dist/config.js`に料金と倍率の節点を集約。

- `initialCoins`: 初期コイン1000
- `blind`: ブラインド100
- `drawingCostPerUnit`: 基準長さごとの料金5
- `drawingCostUnitLength`: 基準長さ（盤面幅を1として、初期値0.25）
- `returnAnchors`: 面積・期待払戻率の節点。節点間は期待払戻率を線形補間し、面積で割って倍率にする。10％以下は×10。
- `maxArea`: 0.85

設定画面でも基準長さを選択できる。ラウンド開始時に設定を固定するため、途中の変更は次ラウンドから適用される。

## 実装したルール

- 開始時にブラインド、抽選時に輪郭の長さに比例した描画コストを支払う。
- 線が自分の線と交差すると、最初の交点で閉じた輪を切り出して即時確定する。輪の前後の余分な線は含めず、確定した輪郭に課金する。始点まで戻って指を離しても確定できる。閉じずに離した線は取り消し（課金なし）。描画中の線は自動で閉じたり塗りつぶしたりしない。
- 始点に24 CSS pxの接続目印を表示する。この範囲に入ると終点が始点へ吸着表示され、範囲内で離した場合に閉鎖を確定する。設定は`closureTolerancePx`。
- 複数領域を追加できるが、領域の接触・重なり・包含、合計面積85％超えは拒否。描画中の自己交差は閉じた輪として切り出す。
- コストと払戻は端数を切り捨て、残高も整数コインで決済する。払戻額の表示を大きく配置する。純利益を表示していた欄は当選時の払戻に変更。
- 玉の中心を盤面内から独立一様抽選し、境界上は当選として扱う。履歴は直近20回。
- 倍率表示は小数第2位までの近似表示。実際の払戻は丸める前の倍率から計算する。
- リセットすると残高・履歴を初期化。ページ再読み込みも初期化される。
- アイコン、リロール、外部決済、アカウント機能は含まない。

## 検証

`node test.cjs`

`node app-test.cjs`

面積、境界判定、交差・重なり、長さによる料金、料金の調整、倍率の節点と期待払戻率の単調低下を検証する。
DOMスタブ上のUIイベントテストでは、開始・描画・取消・当落の精算・履歴・設定の次ラウンド適用・残高不足・リセットを検証する。実機での指の追従感は別途確認が必要。
